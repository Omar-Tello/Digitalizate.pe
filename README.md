# Digitalizate.pe

Sitio web estático integrado y preparado para GitHub y Vercel.

## Estructura

- `/`: introducción
- `/principal/`: página principal
- `/software/`: venta de software
- `/hardware/`: venta de hardware
- `/capacitaciones/`: capacitaciones
- `/diseno-grafico/`: diseño gráfico
- `/ideas/`: envío de ideas

## Publicar en Vercel

1. Sube el contenido de esta carpeta a un repositorio de GitHub.
2. En Vercel, importa el repositorio.
3. Selecciona `Other` como framework.
4. Deja vacío el comando de build y usa `.` como directorio de salida.
5. Publica el proyecto.
